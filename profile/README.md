# Team 404

영남이공대학교 캡스톤디자인 팀입니다. 한국농산의 협력업체 관련 자료를 통합하고 계약 및 인증 만료를 놓치지 않도록 지원하는 관리 서비스 PoC를 준비하고 있습니다.

## 프로젝트 배경

협력업체의 계약, 인증, 발주와 납기자료가 여러 파일과 관리 경로에 분산되면 필요한 정보를 찾는 데 시간이 걸리고 계약·인증 만료를 놓칠 위험이 커집니다.

이번 프로젝트는 흩어진 정보를 협력업체 단위로 연결하고, 만료 예정 항목을 사전에 확인할 수 있는 업무 흐름을 검증하는 것을 목표로 합니다.

## 주요 목표

- 협력업체 기본정보 통합관리
- 업체별 계약 및 인증자료 연결
- 계약·인증 만료 예정일 자동 판정
- 만료 예정 현황 대시보드와 알림
- 발주·납기자료의 통합 조회 방안 검토
- PoC 검증 후 실제 서비스 확장 가능성 평가

## 현재 단계

현재는 기업 미팅 전 기획 및 팀원별 프로토타입 단계입니다.

1. 팀원별 문제 정의와 해결방안 작성
2. 핵심 화면과 데이터 구조 검토
3. 개별 프로토타입 구현
4. 기업 미팅을 통한 요구사항 검증
5. 공통 PoC 범위와 기술 방향 확정

기업의 실제 업무절차, 데이터 항목, 알림 규칙과 배포환경은 미팅 후 확정할 예정입니다.

## 문서 및 보안 원칙

- 확인되지 않은 요구사항은 가설과 초안으로 구분합니다.
- 기업 확인을 거친 내용만 확정 요구사항으로 관리합니다.
- 실제 계약서, 인증서, 개인정보와 영업기밀은 공개 저장소에 저장하지 않습니다.
- 프로젝트 결정과 변경사항은 Git 기록으로 관리합니다.
